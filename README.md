# Lab-Exercise-3

# Aim:
To evaluate and compare the user experience of two competing mobile applications, Google Pay and PhonePe, using Nielsen's usability heuristics, identify usability problems, propose suitable design improvements, and evaluate the impact of the improvements using A/B testing.

# Objectives:
1.To understand the concept of heuristic evaluation in UX design.

2.To compare the UX of Google Pay and PhonePe.

3.To evaluate both applications using Nielsen's 10 usability heuristics.

4.To identify usability problems and areas for improvement.

5.To design improved solutions for the identified problems.

6.To evaluate the effect of design changes using A/B testing.

# Alogorithm:
1.Select two competing applications for UX evaluation.

2.Select Google Pay and PhonePe as the applications for comparison.

3.Study the major features and navigation structure of both applications.

4.Capture screenshots of important screens such as the home screen, payment screen, transaction history, and service sections.

5.Evaluate both applications using Nielsen's 10 usability heuristics.

6.Compare their UI elements, navigation, visual hierarchy, interaction, feedback, and usability.

7.Identify usability problems from the comparison.

8.Rank the identified problems according to their importance and impact on users.

9.Propose suitable UX/UI improvements for the identified problems.

10.Create the improved interface using Figma.

11.Create two versions for testing: Version A: Existing design Version B: Improved design

12.Ask users to perform the same task on both versions.

13.Record task completion, time taken, number of taps, errors, and user preference.

14.Compare the results of Version A and Version B.

15.Analyze whether the proposed design changes improve usability.

16.Document the observations, screenshots, and final results.
